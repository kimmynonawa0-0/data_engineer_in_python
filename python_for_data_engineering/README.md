# Data Engineer in Python 🐍

A collection of hands-on code, exercises, and mini-projects from my journey learning data engineering through **DataCamp**, as part of the **DEP Scholarship 2026 (Data Engineering Pilipinas)** program.

This repo is less about polished, production-ready code and more about **tracking real progress** — every script here reflects something I practiced, struggled with, or finally understood while working through courses and tracks.

---

## 📌 About

I'm a 3rd year BS Computer Science student pursuing a career in **data engineering**. This repository serves as my public learning log — a place to push code from DataCamp exercises, guided projects, and personal practice as I work through the data engineering track.

Not every DataCamp lesson involves code (some are theory-only), so commits here reflect genuine practice sessions rather than a forced daily streak.
